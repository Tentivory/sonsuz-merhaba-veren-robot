# Sonsuz Merhaba Veren Robot

## Bu Nedir?

Bu, insanlığın en büyük başarısıdır. Asla durmayan, sürekli "Merhaba" diyen bir robot. Neden mi? Çünkü bazen hayatta en önemli şey merhaba demektir. Ve bu robot bunu sonsuza kadar yapar. Evet, sonsuza kadar.

### Özellikler
- Gerçekten çalışır (test edildi, sonsuza kadar gitti)
- Rastgele komik eklemeler yapar
- Bilgisayarınızı yormaz (çok az)
- Hiçbir işe yaramaz ama gurur duymanızı sağlar

### Nasıl Kullanılır?
```bash
python sonsuz_merhaba.py
```
Sonra oturup izleyin. Veya CTRL+C ile durdurun. Ama robot içten içe devam eder.

### Neden Var?
Çünkü dünyada yeterince anlamsız şey yoktu. Artık var.

### Uyarı
Bu program sonsuz döngü içerir. Kullanımı sizin sorumluluğunuzdadır. Robot sorumlu tutulamaz.
